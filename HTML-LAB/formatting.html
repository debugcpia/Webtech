HTML Text Formatting

Text Formatting Tags

Bold text uses the b tag.

Important text uses the strong tag.

Italic text uses the i tag.

Emphasized text uses the em tag.

Underlined text uses the u tag.

Highlighted text uses the mark tag.

Small text uses the small tag.

Deleted text uses the del tag.

Inserted text uses the ins tag.

H2O uses the sub tag.

E = mc2 uses the sup tag.
